
# 📊 SmartClient – Dashboard Comportement E-commerce

Bienvenue sur **SmartClient**, un tableau de bord interactif conçu pour analyser le comportement des consommateurs dans un environnement e-commerce.  
Le projet met en avant des **KPI clés**, des **filtres dynamiques** et des **visualisations interactives** pour explorer facilement les données clients.

---

## 🎯 Fonctionnalités principales

- 🔍 **Filtres dynamiques** (Genre, Appareil utilisé, Fidélité)
- 📈 **KPI personnalisés** : Total des achats, satisfaction client, taux de fidélité
- 📊 **Graphiques interactifs** (barres, camemberts, boxplot)
- 🎞️ **Animation mensuelle** de l'évolution des achats
- 💾 **Téléchargement CSV** des données filtrées

---

## 🚀 Lancer le projet

Assurez-vous d'avoir Python + Streamlit installés :

```bash
pip install -r requirements.txt
```

Puis lancez l'app :

```bash
streamlit run Home.py
```

---

## 📁 Structure du projet

- `Home.py` : Page d’accueil et visualisations principales  
- `styles.css` : Feuille de style personnalisée  
- `Ecommerce_Consumer_Behavior_Analysis_Data.csv` : Données analysées  
- `requirements.txt` : Dépendances  
- `README.md` : Documentation
